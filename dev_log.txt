2. Core Data Model (Image)

Defined a POD-style Image struct:

struct Image {
    int width;
    int height;
    int channels;
    uint8_t* data;
};


Image memory is:

linear

row-major

interleaved by channels

Chose uint8_t* for GPU friendliness and explicit memory control

3. Memory Ownership Model (Very Important)

Introduced image_utils.hpp/.cpp

Implemented:

create_image(width, height, channels)

free_image(Image&)

Key rule established:

The caller owns image memory.
Processing functions never allocate or free memory.

Learned why:

prevents leaks & double-free

simplifies pipelines

matches CUDA execution model
